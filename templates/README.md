# Template de projeto

Use esta pasta como referência para criar cada novo projeto dentro de `c:\Projetos`.

## Estrutura sugerida

```text
nome-do-projeto/
├── README.md
├── .gitignore
├── docs/
│   ├── requisitos.md
│   └── decisoes.md
├── src/
├── tests/
└── .env.example
```

## Primeiros arquivos

- `README.md`: propósito, pré-requisitos, instalação, execução e testes.
- `docs/requisitos.md`: MVP, fluxo principal e critérios de aceite.
- `docs/decisoes.md`: decisões técnicas, alternativas consideradas e consequências.
- `.env.example`: nomes das configurações necessárias, sem valores secretos.

O projeto concreto deve adaptar essa estrutura à linguagem e ao framework escolhidos. O objetivo é manter apenas o que ajuda a executar, testar e entender o código.
