# Checklist de novo projeto

Copie este arquivo para a raiz do projeto e marque os itens conforme avançar.

## Problema e escopo

- [ ] Problema descrito em uma frase.
- [ ] Público ou usuário principal identificado.
- [ ] Resultado esperado definido.
- [ ] Fluxo principal descrito em passos.
- [ ] MVP limitado a três a cinco entregas.
- [ ] Critérios de aceite escritos para cada entrega.
- [ ] Funcionalidades futuras separadas do MVP.

## Decisões técnicas

- [ ] Linguagem e versão escolhidas.
- [ ] Framework ou bibliotecas principais escolhidos.
- [ ] Banco de dados definido, se necessário.
- [ ] Forma de configuração local definida.
- [ ] Estratégia de testes escolhida.
- [ ] Justificativas registradas em `docs/decisoes.md`.

## Estrutura e ambiente

- [ ] `README.md` criado com instalação e execução.
- [ ] `.gitignore` criado.
- [ ] Código separado em `src/` ou estrutura equivalente.
- [ ] Testes separados em `tests/` ou estrutura equivalente.
- [ ] `.env.example` criado sem segredos reais.
- [ ] Dependências instaladas de forma reproduzível.

## Primeira validação

- [ ] Comando de instalação executado.
- [ ] Aplicação ou comando principal executado.
- [ ] Teste mínimo passando.
- [ ] Lint, formatador ou compilador executado, quando aplicável.
- [ ] Logs e mensagens de erro compreensíveis.
- [ ] Nenhum segredo ou arquivo temporário versionado.

## Próximo incremento

- [ ] Primeiro incremento escolhido pelo maior valor para o usuário.
- [ ] Tarefa dividida em passos pequenos.
- [ ] Forma de validação definida antes da implementação.
- [ ] Resultado demonstrável ao final da tarefa.
- [ ] Pendências e novas decisões registradas.
